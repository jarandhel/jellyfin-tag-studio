Editing

Adds the edited field to the item's locked fields so a "Replace all metadata" refresh cannot revert your edits. Strongly recommended.
Sets the starting state of the propagate toggle when editing a series. Child items with the field locked are skipped either way.
Off by default. Jellyfin runs its metadata savers once per item, so this writes an NFO for every edited item and is the dominant cost of a large bulk edit. It is also usually pointless: Radarr and Sonarr regenerate those files without your tags. Turn it on only if Jellyfin owns the NFO files for your libraries.

Generated by other plugins

Semicolon-separated. Tags with these prefixes are generated by other plugins (e.g. Language Tags) and are grouped separately and excluded from bulk delete.
Semicolon-separated. Collections whose name contains one of these are generated by another plugin (SmartLists names them "... [Smart]"). Editing one by hand appears to work until the generator next runs, so they are refused - and they are never deleted as empty, since deleting one only invites it back.

Empty collections

Lets the weekly "Delete empty collections" task actually delete. While this is off the task still runs and logs exactly what it would remove, so you can review a few cycles first. Deleting a collection cannot be undone, which is why it is off by default. Collections whose members exist but cannot be resolved - what an offline drive looks like - are never deleted either way.
